# Security

Epinu operates a hosted MCP endpoint (`https://api.epinu.ai/api/agent/mcp`).

**Please do not report security vulnerabilities through public issues.**

Contact: **security@epinu.ai**

Include:

- affected endpoint or tool
- reproduction steps
- potential impact
- whether any real user data was accessed

Please do not test against accounts or data you do not own, and do not
perform denial-of-service or destructive testing. The anonymous read tier
(rate-limited, public data only) is fair game for good-faith probing.
